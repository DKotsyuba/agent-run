# С чего начать

Этот архив содержит написанную на Rust версию основных подсистем agent-run, тесты и документацию. Это **промежуточный исходный код**, не готовый релиз и не подтверждённая полная миграция.

База для переноса: v0.11.15, commit `c9904f9843ba4a0772bdfa8bac5259f18fad9dc3`.

## Что внутри

29 Rust-файлов приложения: типы и конфигурация, профили и политика доступа, файловые операции, SQLite, отдельный супервизор, адаптеры Codex/Claude/GLM/Qwen, сервис, CLI, MCP, Unix socket, квоты и уведомления. Дополнительно включены 78 Rust-тестов и локальный имитатор движка. Python не используется как исполняющая оболочка приложения. Для подписанного процесса Codex Desktop оставлен небольшой JavaScript-мост.

## Что действительно проверено

Десять локальных тестов JavaScript-моста прошли. Схема SQLite создаёт 16 таблиц с user_version 16; 58 SQL-запросов прошли подготовку через SQLite EXPLAIN. Проверены TOML/JSON, наличие встраиваемых файлов и баланс лексических разделителей Rust.

**Компиляция Rust, Rust-тесты, Clippy и rustfmt не запускались:** в среде не было Cargo/rustc, а загрузка инструментов и зависимостей через терминал была недоступна. Cargo.lock не создан. Лексическая проверка не заменяет компилятор. Приведённые количества тестов и модулей не доказывают полноту или работоспособность переноса.

## Что остаётся до полной миграции

Нужны сборка и исправление её результатов, запуск тестов на Linux/macOS и перенос оставшихся функций. В частности, не перенесены старые миграции БД 1–15, продолжение нативных сессий, созданных Python-версией, OmniRoute, сопоставление нескольких аккаунтов Codexbar и fallback авторизации через macOS Keychain. Есть различия в снимках, исходных транскриптах, диагностике, уведомлениях и отдельных возможностях адаптеров.

Полный список: [status.md](status.md). Карта: [architecture.md](architecture.md). План: [port-author-plan.md](port-author-plan.md). Зависимости: [dependencies.md](dependencies.md). Снимок прежних проверок: [REPORT.md](evidence/port-snapshot/REPORT.md).

## Проверка в среде с Rust

```sh
cargo generate-lockfile
# Проверить получившийся Cargo.lock и дерево зависимостей.
cargo fmt --all
cargo xtask check
cargo build --locked --release --package agent-run --bin agent-run
```

Эти команды — инструкция для проверки, а не обещание успешной сборки. Не устанавливайте этот код поверх рабочей Python-версии и не подключайте её активную базу состояния. После успешной сборки используйте отдельный каталог:

```sh
./target/release/agent-run --home "$HOME/.agent-run-rust-eval" init
```

`init` не включает внешние движки автоматически. Для запусков потребуется настроенный движок и запущенный брокер `api serve`; детали находятся в [operator-guide-draft.md](operator-guide-draft.md).

Репозиторий GitHub, рабочая установка и реальные аккаунты при подготовке архива не изменялись.
